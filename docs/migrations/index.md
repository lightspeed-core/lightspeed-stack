# Migration Guides

This page lists upgrade and migration guides for each Lightspeed Core Stack
release that includes breaking or notable configuration changes.

| Version | Description |
|---------|-------------|
| [v0.7.0](v0.7.0.md) | RAG configuration restructured; `ogx` naming; `/v1/vector-stores` and `/v1/conversations` deprecated |
| [v0.8.0](v0.8.0.md) | `inference.context_windows` deprecated in favour of per-model `metadata.context_window`; `GET /a2a` removed; `ogx_version` removed from `/v1/info` |
